# homebrew-formulae

```sh
brew tap daugvinasr/formulae
```

| Formula | Description |
| --- | --- |
| `space-number` | Menu bar space indicator for yabai |
| `yabai` | Tiling window manager for macOS (HEAD-only, builds from [daugvinasr/yabai](https://github.com/daugvinasr/yabai) master) |

```sh
brew install --HEAD daugvinasr/formulae/yabai
brew upgrade --fetch-HEAD daugvinasr/formulae/yabai
```
